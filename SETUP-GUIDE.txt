SWEET MOMENTS — GOOGLE SHEET SETUP

A) GOOGLE SHEET
Create a Google Sheet and put these headings in row 1:
Name | Email | Mobile | Location | Source | Date

B) APPS SCRIPT
Google Sheet -> Extensions -> Apps Script.
Paste the complete code from google-apps-script.gs.
Save.

C) DEPLOY AS WEB APP
Deploy -> New deployment -> Web app
Execute as: Me
Who has access: Anyone
Deploy -> authorize if asked -> Copy Web App URL.

D) CONNECT THE WEBSITE
Open script.js and find:
const GOOGLE_SHEETS_WEB_APP_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";

Replace the placeholder inside the quotes with your Web App URL.
Do not add quotes around the URL twice.
