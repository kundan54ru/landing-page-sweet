STEP 1 — Create the Google Sheet
1. Open Google Sheets.
2. Create a new blank spreadsheet.
3. Give it a name such as:
   Sweet Moments Leads

STEP 2 — Add Google Apps Script
1. In the spreadsheet, click:
   Extensions -> Apps Script
2. Delete the existing code in Code.gs.
3. Open the file named:
   google_apps_script.gs
4. Copy all of its code into Code.gs.
5. Click Save.

STEP 3 — Deploy the Web App
1. In Apps Script click:
   Deploy -> New deployment
2. Select:
   Web app
3. Set:
   Execute as: Me
4. Set:
   Who has access: Anyone
5. Click Deploy.
6. Complete Google's authorization prompts.
7. Copy the Web app URL ending in /exec.

STEP 4 — Connect the landing page
1. Open script.js.
2. Find:
   const GOOGLE_SHEETS_WEB_APP_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";
3. Replace the placeholder with your Web App URL.
4. Save and upload the updated files.

STEP 5 — Test
Submit a test lead.
The Google Sheet should receive:
Timestamp | Name | Email | Phone | Area / Location | Source

IMPORTANT:
- Do not put Google account passwords, API keys, or secret tokens in the landing page.
- The Web App URL is intended to receive form submissions.
- Keep the Google Sheet itself private.
- Test a real submission before running Google Ads.
- For production, consider adding server-side spam protection/rate limiting.
